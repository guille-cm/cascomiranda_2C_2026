Descripción detallada

Implementación del cliente Wi-Fi STA y Servidor Web HTTP embebido con soporte para supervisión clínica en tiempo real, gráficas históricas apiladas desde MicroSD y sincronización automática/manual de fecha y hora RTC.

Administra la máquina de estados de conexión Wi-Fi en modo estación (autenticación WPA2-PSK y obtención de IP por DHCP) y expone una API REST de 10 endpoints sobre el puerto TCP 80:

  • GET / : Sirve el Dashboard HTML5/CSS/SVG/Canvas desde memoria Flash (.rodata).
  • GET /api/status : Entrega el estado integral del sistema en formato JSON cada 1 segundo.
  • POST /api/patient : Actualiza el nombre del paciente (reemplazando la IP en la Fila 0 del LCD).
  • POST /api/msg : Muestra un mensaje clínico en la Fila 0 del LCD (y dispara voz si es "AYUDA EN CAMINO").
  • POST /api/clear_alert : Solicita desencolar la alerta más antigua de la cola FIFO.
  • POST /api/sound_warn : Solicita activar la melodía de advertencia en el parlante.
  • POST /api/play_voice : Solicita reproducir la locución de voz LPCM ("Ayuda en camino").
  • POST /api/time : Recibe el timestamp Unix local desde el navegador y sincroniza el RTC interno.
  • GET /api/sd_history : Recupera los últimos 40 registros de DATALOG.CSV en JSON para las 5 gráficas Canvas.
  • GET /api/sd_csv : Transmite en streaming por bloques de 512 bytes el archivo DATALOG.CSV completo.
